# Appendix C: Bibliography

- Nachum Dershowitz and Edward M. Reingold, “Calendrical Calculations: The Ultimate Edition”, Cambridge University Press, 2018-03-31. ISBN 978-1107683167.

  This book contains a comprehensive description of many calendar systems as well as algorithms to implement them on a computer.

- Jean Meeus, “Astronomical Algorithms”, Willmann-Bell, 2nd edition, 1998. ISBN 978- 0943396613,

  This book contains algorithms for computing astronomical events such as sunrise, sunset, moon phases, etc.

- LeRoy E. Doggett, George H. Kaplan, P. Kenneth Seidelmann, “Almanac for Computers for the year 1978”, United States Naval Observatory.

  This publication contains astronomical tables and algorithms that form the basis of Remind’s sunrise and sunset functions.

- Bernard Desruisseaux (editor), “Internet Calendaring and Scheduling Core Object Specification (iCalendar)”, September 2009.

  This is RFC 5545 and specifies the iCalendar interchange format. It is available online at https://www.rfc-editor.org/rfc/rfc5545.
