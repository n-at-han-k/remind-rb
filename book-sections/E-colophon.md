# Colophon

This book was typeset using the `lualatex` implementation of Leslie Lamport’s L<sup>A</sup>T X computer E typesetting program (based, of course, on Donald Knuth’sT X program.) The main body font is Liberation E Serif and the monospace font is Liberation Mono. In a few places, the fonts Noto Color Emoji and Noto Sans Symbols 2 make an appearance.

The figures are either screenshots of Remind output, or generated on the fly with `remind` and `rem2pdf` as part of the creation of the final PDF; this is done with a `Makefile`.

The EPUB version was generated from the same L<sup>A</sup>T X source files using `tex4ebook`. Only a very small E number of tweaks had to be made to the L<sup>A</sup>T X sources to get them to work properly with `tex4ebook`. E

The L<sup>A</sup>T X input files were prepared with GNU Emacs on a Debian 13 Linux system. E

No generative AI was used in the production of this book.
